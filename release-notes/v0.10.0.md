## 한국어

MusicSync 첫 통합 릴리스입니다. Mac·iPhone·Android·Windows·Linux 앱과 새 웹 수신 클라이언트를 제공합니다. 클라우드 없이 LAN에서 네이티브 호스트를 검색하고, 코드 비교·호스트 승인·TLS 암호화 후 재생 시각이 포함된 48 kHz 스테레오 PCM을 예약 재생합니다.

### 새 웹 클라이언트

- LAN HTTPS/WSS 게이트웨이를 통한 Bonjour 호스트 검색 및 별도 기기 페어링
- 시계 동기화·적응형 지터 버퍼·스테레오/왼쪽/오른쪽 채널·출력 보정
- 호스트 권한을 따르는 볼륨/기기 제어와 식별음, 연결 끊김 후 자동 재연결
- 한영 UI, Material 스타일, 실시간 지연/동기화 수치, 로그·도움말·GitHub 링크
- 동기화 시작 후 30초 준비 및 5초 지속 조건을 적용하는 경고
- 중복 탭 기기 ID 충돌 방지, 기억한 호스트 키 변경 시 연결 거절

### 설치·제한

- **iOS IPA는 unsigned**입니다. Apple 서명/프로비저닝 또는 호환 설치 도구가 필요하며 일반 App Store IPA처럼 바로 설치할 수 없습니다. 이 릴리스에서 LiveContainer 호환성을 실기기로 보증하지 않습니다.
- macOS 앱은 ad-hoc 서명을 포함하지만 Developer ID 서명·공증은 없습니다. 최초 실행의 macOS 보안 설정과 오디오 캡처/로컬 네트워크 권한을 확인하세요.
- Android APK는 CI debug 키로 서명했습니다. 기존 설치와 키가 다르면 업데이트가 거절될 수 있습니다.
- 웹은 Node.js 22+/OpenSSL 및 본인 기기의 개인 CA 신뢰 설정이 필요합니다. `npm run setup` → `npm start` 후 터미널 초대 URL을 여세요. 인증서 개인 키·페어링 비밀은 배포 파일에 포함하지 않습니다.
- 첫 웹 버전은 기존 네이티브 호스트에 연결하는 **수신기**입니다. 브라우저 단독 호스팅·네이티브 Dynamic Island·보장된 백그라운드 재생은 지원하지 않습니다. 웹 볼륨은 앱 볼륨입니다.
- 설계상 공통 버퍼는 180–500 ms입니다. 실제 스피커 간 음향 오차는 Wi-Fi·출력 장치·브라우저 상태에 따라 달라지며 ±3 ms를 보증하지 않습니다. iPhone Safari 실기기 검증은 남아 있습니다.
- 동기화 프로세스 탭/파일 재생과 달리 시스템 오디오 모니터 캡처는 원래 호스트 소리를 지연시키지 않아 먼저 들릴 수 있습니다. DRM/OS 캡처 제한이 적용될 수 있습니다.

## English

First combined MusicSync release: native apps for macOS, iOS, Android, Windows and Linux, plus the new LAN browser receiver. No cloud streaming service. Native host discovery, manual code comparison/host approval, TLS encryption, clock synchronization and timestamped 48 kHz stereo PCM playback are implemented.

The web client adds an HTTPS/WSS LAN gateway, adaptive buffering, channel selection/output trim, permission-gated host/peer controls, identification sounds, automatic reconnection, Korean/English UI, live metrics, logs and help. Warnings require a 30-second warm-up and a sustained five-second condition. Duplicate browser tabs cannot repeatedly replace each other's device connection; remembered host key changes fail closed.

Native Apple apps retain **0.8.0 build 11**, desktop/Android ports **0.9.0** (Android build 12), and web **0.10.0**. The release tag identifies the combined tested source snapshot, not a change to every app's internal version. See the download table above. Windows/Linux include their Java runtime; `SHA256SUMS.txt` covers all downloadable binaries.

**Installation and limits:** iOS IPA is unsigned and requires signing/provisioning or a compatible installer; physical LiveContainer compatibility is not guaranteed. macOS is ad-hoc signed without Developer ID signing or notarization. Android uses a CI debug key that may differ from earlier installations. Web requires Node.js 22+, OpenSSL and trusted private LAN CA setup; run `npm run setup`, then `npm start`, and open the invitation URL. Web is receiver-only with app gain, and does not provide native Live Activities or guaranteed background playback. The trusted local gateway terminates both TLS hops; this is not browser-to-host end-to-end encryption. Keep its keys/secrets private.

Shared buffer design is 180–500 ms; physical acoustic synchronization, Safari/mobile background behavior and route latency require device validation. Monitor capture leaves original host output undelayed. DRM/system capture restrictions may apply. Source remains **MIT**; dependency licenses are preserved in the distributions.
